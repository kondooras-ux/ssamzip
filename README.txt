쌤ZIP 3.0 - 윈도우용 압축 프로그램 (zip / 7z)
=====================================================

■ 바로 써보기 (파이썬이 설치된 PC)
  1) 이 폴더를 원하는 곳에 둡니다.            예) C:\Tools\SsamZip
  2) 명령 프롬프트에서  pip install -r requirements.txt
  3) run.bat 을 더블클릭
  4) [설정] 탭 → 우클릭 메뉴 '등록', zip/7z 더블클릭 '등록'

■ 파이썬 없는 PC에 배포하려면 (exe 만들기)
  1) build_exe.bat 더블클릭  (1~3분)
  2) dist\ssamzip 폴더가 생깁니다. 폴더 통째로 원하는 곳에 복사
  3) ssamzip.exe 실행 → [설정] 탭에서 등록
  * exe 한 개짜리를 원하면:  python build.py --onefile
    (켤 때마다 느리고 백신이 의심할 수 있어 폴더형을 권장합니다)

■ 기능
  [압축하기]   파일/폴더를 끌어다 놓기 → ZIP(AES-256 암호 가능) 또는 7z
               이미 압축된 파일(jpg, mp4, docx, hwpx 등)은 다시 압축하지 않아 훨씬 빠름
               Thumbs.db, ~$임시파일 자동 제외
  [풀기]       내용 미리보기, 암호, 같은 이름 처리(이름 바꿔 저장/덮어쓰기/건너뛰기)
               '압축 파일 옆에 폴더 만들기'는 폴더가 겹치지 않게 정리
               (예: 홍길동.zip 안에 '홍길동' 폴더가 또 있어도 한 겹만 생김)
  [폴더 일괄 풀기]  학생 제출 폴더 선택 → 안의 zip/7z를 전부 이름 폴더로 풀기
               하위 폴더 포함, 한 폴더에 모아서 풀기, 암호 걸린/깨진 파일은 표에 사유 표시
               성공한 건 건너뛰고 실패한 것만 다시 처리 가능, 여러 파일 동시 처리
  한글 파일명  알집/구형 윈도우/맥에서 만든 zip의 깨진 한글 이름을 자동 복원
               맥 zip의 __MACOSX, .DS_Store 찌꺼기는 자동 제외

■ 3.0에서 달라진 점 (압축 성능 + 새 기능)
  [압축 성능]
  - ZIP 병렬 압축: 파일을 나눠 CPU 코어 수만큼 동시에 압축 (큰 파일/폴더일수록 빠름)
  - ZIP '초고압축(느림)': Zopfli 방식. 결과는 평범한 ZIP이라 아무 프로그램으로나 열리고,
    같은 ZIP 최대 압축보다 데이터에 따라 0~6% 더 작아짐. 대신 수십 배 느리니 '보내기 전 마지막 한 번'에 쓰세요.
    (암호 ZIP은 속도 구조상 지원 안 함 → 최대 압축으로 처리)
  - 압축 안 되는 파일 자동 판별: 확장자가 아니라 내용을 시험해 보고 이득이 없으면 저장만
    (PNG처럼 조금이라도 줄어드는 건 압축). 결과가 더 커지면 자동으로 저장으로 되돌림
  - 7z: 같은 종류 파일끼리 묶어 압축, 실행파일(exe/dll)이 많으면 x86 변환 필터 자동 적용(약 4% 절감),
    '초고압축'은 설정 두 가지를 모두 해 보고 작은 쪽 선택
  [새 기능]
  - 무결성 검사: 압축 파일을 풀지 않고 전부 읽어 보며 깨진 파일 찾기 ([풀기] 탭)
  - 나눠 저장(분할 압축): 700MB, 4GB(FAT32 USB), 직접 입력. a.zip.001, .002 ... 형식 (7-Zip과 같은 이름 방식)
    풀 때는 .001 파일을 선택 (끌어다 놓기·일괄 풀기도 됨)
  - 선택한 것만 풀기, 내용 검색(필터), 항목 더블클릭하면 임시로 풀어서 바로 열기
  - 파일 이름 글자 선택(자동/UTF-8/CP949): 자동으로 안 맞는 드문 zip용
  - 일괄 풀기 '암호 후보': 학생마다 암호가 달라도 후보를 한 줄에 하나씩 적어 두면 파일마다 맞는 걸 찾아 풀기
  - zip ↔ 7z 변환 기능은 엔진(core.convert_archive)에 있고 화면 버튼은 아직 없음
  - 우클릭 '바로 압축'은 기다리지 않도록 설정 수준이 '초고압축'이어도 최대 압축까지만 씁니다

■ 탐색기 연동 ([설정] 탭에서 등록 / 해제, 관리자 권한 불필요)
  파일·폴더 우클릭   쌤ZIP으로 압축 (창 없이 바로)  /  쌤ZIP으로 압축 (암호·옵션)
  zip·7z 우클릭      쌤ZIP: 여기에 풀기  /  쌤ZIP: 폴더 지정해서 풀기
  폴더 우클릭        쌤ZIP: 폴더 안 압축파일 전부 풀기  (폴더 빈 곳 우클릭도 가능)
  여러 개를 선택하고 우클릭해도 하나로 합쳐서 처리합니다.
  * 윈도우 11은 우클릭 → '추가 옵션 표시'(또는 Shift+F10) 안에 나타납니다.
  * zip 더블클릭: 윈도우 정책상 프로그램이 기본 앱을 직접 바꿀 수 없습니다.
    [설정]에서 '등록'을 누르면 열리는 '기본 앱' 화면에서 .zip / .7z 를 쌤ZIP으로 한 번만 고르세요.
    (또는 zip 파일 우클릭 → 연결 프로그램 → 쌤ZIP)

■ 문제 해결
  - 우클릭 메뉴가 안 보여요       → 윈도우 11은 '추가 옵션 표시' 안을 확인
  - 폴더를 옮기거나 이름을 바꿨어요 → [설정]에서 '해제' 후 다시 '등록' (메뉴가 옛 위치를 가리킴)
  - 백신이 exe를 막아요           → 폴더형으로 빌드(기본값)하고 예외 등록
  - 암호 걸린 7z는 파일 이름도 숨겨져서, 암호를 넣어야 내용이 보입니다
  - 오류 기록   %APPDATA%\SsamZip\error.log
  - 설정 파일   %APPDATA%\SsamZip\settings.json  (지우면 초기화)

[3.1 점검·개선 내용]
- 읽을 수 없는 파일(다른 프로그램이 잠금, 권한 없음, 끊어진 바로가기)은 전체를 멈추지 않고 건너뛴 뒤 완료 창에서 목록으로 알려 줍니다.
- 디스크 가득 참/권한/경로 너무 김 등 오류를 한글 안내 문구로 바꿨습니다.
- 압축 안의 위험 경로(Zip Slip)·이름 충돌·대소문자만 다른 이름은 해당 항목만 건너뛰고 보고합니다.
- 수정 시각이 2107년 이후인 파일도 압축됩니다.
- 인터넷에서 받은 압축 파일의 '출처 표시(Zone.Identifier)'를 푼 파일에 옮겨, 스마트스크린/보호 보기가 유지됩니다.
- 설정 파일이 깨져도 기본값으로 시작합니다.

[3.2 새 기능]
- 형식: TAR / TAR.GZ / TAR.BZ2 / TAR.XZ / GZ·BZ2·XZ(파일 1개) 만들기, RAR·CAB·ISO·LZH·CPIO 등 풀기(윈도우 내장 tar.exe 사용, 암호 RAR·분할 RAR 제외)
- 자동 업데이트(설정 탭 → 업데이트): 주소를 적어 두면 시작할 때 하루 한 번 새 버전을 확인하고, SHA-256이 맞는 파일만 설치합니다.
- 변경 이력 보기, 파일 SHA-256 계산, 빌드 정보 표시
- 점검: python selftest.py  (모든 형식 한 바퀴 시험)

[자동 배포 설정 방법 (GitHub)]
1. GitHub에 '공개(Public)' 저장소를 만듭니다. (비공개 저장소는 업데이트 파일을 받을 수 없습니다)
2. 이 폴더의 모든 파일(.github 폴더 포함)을 올립니다.
3. 저장소 Settings → Actions → General → Workflow permissions 를 'Read and write' 로 바꿉니다.
4. Actions 탭 → release → Run workflow (force 체크) 로 첫 배포를 만듭니다.
5. 쌤ZIP 설정 탭의 '업데이트 주소'에 https://github.com/아이디/저장소 를 적습니다.
이후에는 매주 월요일 새벽 3시(한국 시간)에 라이브러리 새 버전을 받아 자체 점검을 통과하면 버전을 올려 자동으로 배포합니다.
- 배포 파일에는 SHA256SUMS.txt(해시)와 latest.json(업데이트 안내)이 함께 올라갑니다.
- 저장소 계정에는 반드시 2단계 인증을 켜세요. (업데이트 파일의 출처를 보증하는 것은 그 계정뿐입니다)
- GitHub Actions 설정은 이 개발 환경에서 실제로 돌려 보지 못했습니다. 첫 배포 때 Actions 탭의 로그를 확인해 주세요.
- GitHub 없이 쓰려면 학교 서버 등 https 주소에 latest.json과 zip을 올리고 그 주소를 적으면 됩니다. (python build.py --release 가 release 폴더에 만들어 줍니다)
